# MyGraduationApp

## 📝 サービス概要

学習内容を記録・可視化することで、継続的な学習をサポートするアプリです。

## 🎯 ターゲットユーザー

* 学習を継続したい人
* 自分の成長を振り返りたい人
* 学習記録を手軽に管理したい人

## ❗ ユーザーの課題

学習を続ける中で、以下のような課題を感じていました。

* 自分が何をどれだけ学習したのか把握しづらい
* 成長を実感しにくく、モチベーションが続かない
* 記録をつけるのが面倒で継続できない

## 💡 解決方法

シンプルに学習記録を投稿・管理できる仕組みを提供し、
過去の記録を簡単に振り返られるようにしました。

## 🚀 主な機能

* ユーザー登録 / ログイン機能
* 学習記録の投稿・編集・削除（CRUD）
* 学習記録一覧表示
* 検索機能

## 🛠 使用技術

* Ruby 3.1.4
* Rails 7.0.10
* PostgreSQL
* Render

## 💡 工夫した点

* シンプルなUIにすることで、記録のハードルを下げた
* 検索機能を実装し、過去の学習を振り返りやすくした
* MVCの責務分離を意識し、保守しやすい構成にした

## 🧠 技術的なこだわり

* RESTfulな設計を意識したCRUD実装
* バリデーションによるデータ整合性の担保
* 可読性を意識したコード設計

## 🔧 今後の改善点

* オートコンプリート機能の追加
* OpenAI APIを活用した学習分析機能
* UI/UXの改善
* 利用規約・プライバシーポリシーの整備
